\doxysubsubsection{\texorpdfstring{opcontrol()}{opcontrol()}}
{\footnotesize\ttfamily void opcontrol (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption})}

Runs the operator control code. This function will be started in its own task with the default priority and stack size whenever the robot is enabled via the Field Management System or the V\+EX Competition Switch in the operator control mode.

If no competition control is connected, this function will run immediately following \mbox{\hyperlink{main_8cpp_a25a40b6614565f755233080a384c35f1}{initialize()}}.

If the robot is disabled or communications is lost, the operator control task will be stopped. Re-\/enabling the robot will restart the task, not resume it from where it left off.
